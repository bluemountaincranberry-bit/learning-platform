## Purpose

Устанавливает проверяемый контракт именования и единый предметный словарь для PHP, API и TypeScript без неоднозначности идентификаторов.

## ADDED Requirements

### Requirement: Проверяемая форма имён

Проверка конвенций SHALL обнаруживать несовместимые имена файлов и публичных символов в мигрированных областях и указывать ожидаемую форму.

#### Scenario: Нарушенная форма

- **WHEN** новый публичный символ не соответствует соглашению
- **THEN** проверка сообщает символ, файл и ожидаемое правило

#### Scenario: Разрешённое исключение

- **WHEN** framework требует особого имени, внесённого в узкий список исключений
- **THEN** проверка принимает его без отключения остальных правил

### Requirement: Единый предметный смысл

Публичные контракты SHALL различать каноническую лексему, связь с контентом, кандидата, review и попытку упражнения; перенос формата MUST сохранять значение и тип идентификаторов.

#### Scenario: Mapping API

- **WHEN** wire payload преобразуется в frontend модель и обратно
- **THEN** контрактная проверка подтверждает сохранение contentLexemeId и отличие от lexemeId

#### Scenario: Review терминологии

- **WHEN** добавлено новое публичное поле предметного контракта
- **THEN** review сверяет термин со словарём и фиксирует смысл до принятия изменения
