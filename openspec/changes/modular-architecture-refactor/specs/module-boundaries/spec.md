## Purpose

Обеспечивает проверяемое владение состоянием и обнаружение нарушений межмодульных зависимостей при проверке изменений.

## ADDED Requirements

### Requirement: Проверка зависимостей

Архитектурная проверка SHALL завершаться ошибкой при обращении к приватной реализации другого модуля или запрещённом цикле зависимостей.

#### Scenario: Запрещённая зависимость

- **WHEN** проверяемое изменение импортирует приватную модель другого модуля
- **THEN** проверка сообщает исходный файл, зависимость и нарушенное правило

#### Scenario: Публичная граница

- **WHEN** изменение обращается к разрешённому публичному контракту
- **THEN** проверка принимает зависимость

### Requirement: Владение бизнес-операцией

Изменение состояния SHALL проходить через сценарий владельца с проверкой действующего пользователя и бизнес-инвариантов.

#### Scenario: Чужой ресурс

- **WHEN** пользователь пытается изменить чужой учебный ресурс
- **THEN** операция отклоняется без изменения состояния и раскрытия чужих данных

#### Scenario: Атомарный review

- **WHEN** обязательная часть обработки review завершается ошибкой
- **THEN** связанные изменения карточки, истории и обязательного учебного результата откатываются
