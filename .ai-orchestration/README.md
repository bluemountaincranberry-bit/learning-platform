# AI Orchestration

Эта папка описывает, как вести задачи через главного агента и специалистов.
Она не привязана к Codex, Claude или другой платформе.

## Как пользоваться

1. Главный агент читает:
   - `QUICK_START.md`, если нужен пример запуска
   - `profiles/vika.md`
   - `profiles/project.md`
   - нужный файл из `workflows/`
2. Главный агент выбирает роли из `agents/`.
3. Для каждой роли он передает короткий context packet, а не весь чат.
4. Специалист возвращает результат в заданном формате.
5. Главный агент принимает решение о следующем шаге.

## Структура

- `profiles/` - постоянный контекст: Вика, проект, обучение.
- `core/` - общие правила процесса: gates, context packets, отчеты.
- `agents/` - роли специалистов и их контракты.
- `workflows/` - сценарии прохождения задачи.
- `adapters/` - как запускать этот процесс в конкретной платформе.
- `templates/` - шаблоны входа, предложения, плана и финального отчета.
- `local-tasks/` - временные markdown-задачи на русском.
- `project-docs/` - короткая актуальная документация проекта.

## Главные файлы

- `QUICK_START.md` - готовые команды для запуска.
- `workflows/task-lifecycle.md` - полный жизненный цикл задачи.
- `project-docs/project-overview.md` - быстрый контекст проекта.

## Основные режимы

- `research first` - сначала исследовать идею или задачу, затем спросить Вику, переходить ли к локальной задаче, набору задач или implementation.
- `proposal first` - сначала предложить вариант решения, затем ждать approval.
- `implement directly` - для маленьких понятных задач сразу реализовать и проверить.
- `learning mode` - делать задачу и коротко объяснять полезные инженерные принципы.

## Локальные задачи

Если задача большая, агент создает временную markdown-задачу в `local-tasks/`
на русском языке.

После завершения implementation задача удаляется из `local-tasks/`.
Постоянные знания переносятся только в `project-docs/` или обычные docs проекта.

## Главное правило

Главный агент держит полную картину. Специалисты получают только нужный
контекст для своей роли и возвращают структурированный результат.
