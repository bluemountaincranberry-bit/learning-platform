# Local Tasks

Здесь временно лежат markdown-задачи на русском языке.

Правила:

- создавать только после research/proposal и подтверждения Вики;
- одна задача - один файл;
- файл удаляется после завершения implementation;
- постоянные знания переносить в `../project-docs/` или обычные docs проекта.

Это рабочий буфер, а не постоянная документация.
