# Context Packet

Context packet - это короткая передача задачи специалисту.
Не передавать специалисту весь чат без необходимости.

## Формат

```markdown
## Role
<какой агент сейчас работает>

## Task
<что нужно сделать>

## Context
<короткий нужный контекст>

## Read
<какие файлы или документы прочитать>

## Constraints
<что нельзя менять или нарушать>

## Output
<какой результат вернуть>

## Next Step
<что главный агент сделает с результатом>
```

## Правило

Если специалисту нужен дополнительный контекст, он должен явно сказать,
какого контекста не хватает и почему.
