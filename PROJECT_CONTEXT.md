# Project Context

## Продукт

Learning App — AI-приложение для изучения любого языка через реальный контент.
Начинаем с английского; язык нигде не захардкожен.

Основной цикл: материал попадает в приложение (YouTube, групповые уроки с
заметками, фото и PDF, позже субтитры и книги) → AI предлагает самое ценное
(слова, фразы, грамматику) → ученик выбирает и сохраняет → повторяет и
запоминает. Подробно и с приоритетами: skill `product-owner` (`VISION.md`,
`DECISIONS.md`).

Сейчас единственный пользователь — Вика (ломать API и схему можно, её данные
сохраняем). Строим так, чтобы приложение было готово к продакшену для других
учеников. Проект ещё и учебная площадка Вики: агентная AI-платформа и практики
enterprise-приложений.

## Принципы

- **Enterprise-режим.** Расширяемо, с запасом на рост, по best practice и ADR.
- **Продумываем до конца.** Все сценарии и нужды пользователя, граничные случаи,
  следующий шаг продукта.
- **Полнее, а не минимально.** Абстракции, модули, события, расширение API и
  модели данных — норма, когда служат продукту и архитектуре.
- **Качество встроено.** Тесты, ясные границы модулей, документированные решения.
- **Стоп-линии:** живой каталог публикует человек, `main` меняет только Вика,
  данные пользователей сохраняются.

## Стек

- Backend: Laravel 12, PHP 8.2; admin: Filament 5.
- Frontend: Vue 3 SPA, TypeScript, Pinia, Vue Router, Vite.
- Auth: Sanctum, Spatie Permission. Поиск: Scout + Elastic.
- Ops: Horizon, Pulse, Telescope, Pail. Тесты: Pest.
- Инфраструктура: Docker, Postgres, Redis.

## Модули (modular monolith)

Перед изменением определи модуль-владелец по бизнес-смыслу.
Код модулей: `src/app/Modules/<Module>`.

| Модуль | Отвечает за |
|---|---|
| `User` | auth, роли, права, профиль, настройки |
| `Content` | источники, каталог, обработка, видимость, модерация, извлечение лексем |
| `Learning` | study flow, уроки, learned state, сессии, прогресс |
| `Srs` | интервальное повторение, due items, история повторений |
| `Ai` | объяснения, чат, рекомендации, embeddings, провайдеры, агенты |
| `Admin` | backoffice и операционные сценарии (Filament) |
| `Integrations` | внешние API, OAuth, webhooks, контракты |
| `Infrastructure` | очереди, события, мониторинг, логи, Redis, Horizon |

Взаимодействие по природе работы: прямой вызов для синхронного use case,
job/queue для тяжёлой, внешней или фоновой работы, событие для бизнес-факта и
его побочных эффектов (аналитика, уведомления, интеграции).

## SPA

`src/resources/js/spa/`: `pages/` — экраны маршрутов, `widgets/` — shell и
крупные блоки, `domains/` — API, типы и hooks по бизнес-областям, `shared/ui/` —
UI-примитивы. Mobile first; дашборд — главная точка входа.
