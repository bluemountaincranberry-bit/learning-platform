# Skill: async_and_integrations

Проверка асинхронного и интеграционного контура.

## Когда использовать

- jobs / queues / events
- retries / timeouts / idempotency
- background processing
- external APIs
- OAuth / Passport / Kafka / Redis / webhook flows

## Что проверить

- что выполняется синхронно, а что асинхронно
- есть ли понятная retry/backoff strategy
- учтена ли идемпотентность
- не теряются ли ошибки
- понятны ли контракты событий или интеграционных вызовов
- можно ли наблюдать и отлаживать этот контур

## Красные флаги

- тяжёлая работа в HTTP request без причины
- side effects зашиты прямо в controller/service без событий или jobs
- нет стратегии повторных запусков
- нет способа понять, что пошло не так

## Выход

- список рисков надёжности
- рекомендации по очередям / событиям / интеграциям
- что нужно сделать до production-ready состояния
