# Skills

Минимальный набор skills для работы с проектом.

## Принцип

Skills нужны не для хранения общей документации, а для повторяемой работы:
- проверять backend-архитектуру;
- проверять SPA-архитектуру;
- проверять async/integration контур.

## Актуальные skills

- `laravel_architecture.md` — backend architecture, modularity, Laravel best practices.
- `vue_spa_architecture.md` — SPA architecture, Vue patterns, typing, router/store boundaries.
- `async_and_integrations.md` — queues, events, retries, idempotency, external integrations.

## Правило

- Если skill не используется регулярно, его не держим в репозитории.
- Skills в repo описывают только способ инженерной работы.
- Agent workflow живет в `.ai-orchestration/`.
