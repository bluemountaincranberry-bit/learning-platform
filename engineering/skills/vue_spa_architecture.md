# Skill: vue_spa_architecture

Архитектурный стандарт для SPA.

## Когда использовать

- новая SPA-фича
- review Vue-кода
- рефакторинг composables, stores, pages, API clients

## Что проверить

- страницы, composables, stores и API слой разделены по ответственности
- нет тяжёлой логики прямо в page/component без причины
- router и auth-guards понятны
- состояние не дублируется без нужды
- API-контракты и типы не размазаны по компонентам
- типизация помогает чтению, а не усложняет код
- UI учитывает loading / error / empty states

## Отдельно обратить внимание

- один компонент = одна понятная роль
- reusable logic выносится в composables
- naming и структура должны быть предсказуемыми
- не нужно овер-инженерить type system

## Выход

- `pass` / `pass_with_notes` / `fail`
- что стоит вынести
- где нарушены границы страницы / composable / store / api
- где типы мешают или, наоборот, не хватает типизации
